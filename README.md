# FM Energy Workshop

## Overview

This is a **workshop prototype** project aimed at predicting the next hour's building electricity consumption and displaying the forecast on an interactive dashboard.

## Goal

- Predict next-hour building electricity consumption
- Visualize the prediction on a live dashboard

## Planned Tools

| Tool | Purpose |
|------|---------|
| **Python** | Core language for data processing and modeling |
| **Streamlit** | Interactive web dashboard for visualizing predictions |
| **Neon Postgres** | Serverless PostgreSQL database for storing consumption data |

## Status

> This project is a **workshop prototype** and is under active development.
